# Tic Tac Toe

A polished tic-tac-toe game built with React, TypeScript, Vite, and Tailwind CSS.

Features: 2-player local mode, vs. computer (minimax AI), score tracking, win detection with animated highlights, responsive design, and dark mode support.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
